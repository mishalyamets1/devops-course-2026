# Мои заметки

## Что удобно в VS Code

1. **Встроенный терминал** — можно выполнять команды Git и другие команды, не переключаясь в отдельное приложение.
2. **Быстрый поиск файлов и текста** — сочетание `Cmd + P` помогает быстро открыть файл, а `Cmd + Shift + F` найти текст во всём проекте.
3. **Подсветка синтаксиса и автодополнение** — код легче читать, а VS Code подсказывает доступные команды и имена файлов.

## Что удобно делать в терминале

- **Проверять состояние Git командой `git status`** — сразу видно изменённые файлы и текущую ветку.
